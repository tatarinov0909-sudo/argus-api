# Закрытый просмотр лендинга

27.09.2026. По решению владельца добавлен отдельный вход «Лендинг» на основной странице кабинетов. Это приватный просмотр дизайна владельцем, не новая складская роль и не публичная маркетинговая публикация.

- Вход: `https://argus-ai.online/login.html` (также корень основного сайта).
- Защищённый адрес: `https://api.argus-ai.online/landing-preview/`.
- Форма: `/landing-preview/login`; выход: POST `/landing-preview/logout` с Origin текущего API.
- Маршруты: `src/landing-preview/routes.js`, подключение в `src/app.js`.
- Файлы на сервере: `/opt/argus-api/private/landing-preview/`. Они доступны только через middleware авторизации, включая JS, изображения и JSON.
- Пароль задан владельцем. В серверном `.env` хранится только bcrypt-хэш `LANDING_PREVIEW_PASSWORD_HASH` (12 раундов). Не копировать значение в исходники или документы. Для смены заменить хэш и перезапустить процесс API.
- Отдельная подписанная сессия, Secure/HttpOnly/SameSite=Strict cookie, срок 8 часов. Ключ не связан с JWT складских кабинетов, генерируется при запуске; перезапуск API завершает сессии просмотра.
- Десять неверных попыток с адреса за 15 минут; проверяется Origin отправки формы. `Referrer-Policy: same-origin` необходим, чтобы нормальная отправка формы сохраняла Origin (с `no-referrer` браузер отправлял `null`).
- Нет хэша — закрыто с 503. Нет сессии — форма для страниц, 401 для файлов. Все ответы `private, no-store`, поисковая индексация запрещена.

## Публикация и обновление сцены

Исходники сцены находятся в соседнем `argus-landing-scene`. Его `tools/package_private_preview.py <новая-папка>` собирает только необходимые браузерные файлы и tar.gz. Не загружать Blender-проекты, историю, документы и секреты. Текущий пакет — 40 файлов, около 20,7 МБ, сцена v82 r2.

При обновлении сделать резервную копию текущей папки, загрузить проверенный пакет и заменить каталог. Защита маршрута должна оставаться включённой. Нельзя копировать эти файлы в публичный document-root основного сайта. Для проверки смены освещения внутри защищённого каталога есть `story-preview.html`.

API опубликован через `deploy/release.sh` с резервным копированием приложения и базы; миграций нет. Последний бэкап приложения: `/opt/argus-backups/landing-form-origin-20260927-211425`. Первый релиз: `/opt/argus-backups/private-landing-preview-20260927-211212`. Резервная копия конфигурации создана отдельно в каталоге `landing-preview-config-*` с закрытыми правами.

## Проверка

Целевой `node --test test/landing-preview.test.js` проходит: отсутствие настройки, закрытые файлы, неверный пароль, чужой Origin, отдельная сессия, защищённые cookie, подделка токена, скрытые файлы, обход пути, ограничение попыток и выход. Эти тесты не используют БД.

На живом сайте пройден путь с пятого входа через форму до сцены: 7962 частицы, актуальное ночное небо, ошибок консоли нет. Неверный пароль и закрытие файлов проверены также HTTP-тестами. Общий набор тестов API был запущен, но тесты tenant-isolation не прошли из-за отсутствия локального PostgreSQL; не считать весь набор зелёным. Рабочая БД этими проверками не использовалась.

Широкий экран и прокрутка до пятого входа проверены в браузере. Запрошенное изменение размера viewport в инструменте не применилось; мобильную проверку не считать выполненной.
