# Независимая проверка 01.10.2026 — отчёт

Проверял независимый агент без контекста: `argus-api` на коммите `feb8fef`, `argus-product` — на `906f0fd`. Код не менял, на рабочий сервер и в настоящий WB не ходил. Тесты гонялись на одноразовой базе `argus_seller_test_attack0110`. Каждый тест падает на текущем коде (код выхода 1); код выхода 2 означает, что сломался сам тест. Находки 1–4 перепроверены отдельно.

Запуск — из `argus-api`, переменные как в `test/attack-2809`:
`node test/attack-0110/<файл>.js`.
Экранные тесты (`ui-*`) требуют Playwright: `ARGUS_PLAYWRIGHT_MODULE=<путь к playwright>`.

## Находки, от самой серьёзной

1. **Переименование склада убирает из работы заказы WB у всех продавцов.** Блокирует.
   Тест: `settings-rename-warehouse-hides-all-wb-orders-e2e.js`.
   Место: `src/warehouses/routes.js:92-94` пересчитывает отметки при любом изменении `name`/`wbNames`; экран (`cabinet_main.js`) отправляет оба поля при каждом сохранении.
2. **«Слим Тим»: стоит продавцу завести на WB второй склад — все его заказы уходят из работы.** Блокирует.
   Тест: `wb-single-warehouse-unmarked-when-seller-adds-second-e2e.js`.
   Место: `sellerWarehouses.js` — `autoOurs` и `applyAuto`: решение правила не закрепляется.
3. **Пустой ответ WB на список складов продавца убирает все его заказы.** Блокирует при сбое WB.
   Тест: `wb-empty-warehouse-list-hides-orders-e2e.js`.
   Место: `sellerWarehouses.js` — `refresh` проставляет `gone_at` всем складам.
4. **После смены пароля владельца старые входы продолжают работать** (и продлеваются). Безопасность.
   Тест: `owner-password-change-keeps-old-sessions-e2e.js`.
   Место: `auth/service.js` (смена пароля), `middleware/auth.js` (токен владельца ни с чем не сверяется).
5. **Галочка склада или «Обновить из WB» во время обмена с WB падают с 409 «Склад занят…».** Причина — взаимная блокировка: обмен и галочка берут строки в разном порядке.
   Тест: `wb-checkbox-and-refresh-during-sync-deadlock-e2e.js`.
6. **Возвращённый заказ теряет историю в журнале** (`ON DELETE SET NULL`).
   Тест: `wb-restored-order-loses-journal-history-e2e.js`.
7. **Заказ, стоящий в поставке, одновременно попадает в отложенные.** Из-за этого счётчики «не в работе» и «вернулось» врут.
   Тест: `wb-hidden-counter-counts-orders-in-work-e2e.js`.
8. **Карточка продавца не показывает ждущие заказы, если ключ WB отключён.**
   Тест: `ui-sellers-card-hides-waiting-orders-without-key.js`.
9. **Ссылки на `argus-sync-1c-10.3.zip` ведут на файл, которого нет в репозитории сайта.**
   Тест: `site-1c-module-link-file-missing.js`.

## В порядке

- Изоляция между складами и продавцами.
- Права ролей.
- Проверка ввода в настройках.
- Поставка только из заказов одного склада WB.
- Обычная работа галочек.
- Окно продавца и вкладка «Склады WB»: на телефоне, с длинными названиями, с экранированием.
- Часовой пояс склада.

## Замечания без теста

- Менеджер без прав может ставить галочки складов WB через API.
- Пояс «+03:00» принимается сервером.
- «Доступно» у продавца считается только по товарам с учётом, поэтому числа на экране могут не сходиться.
- Подсказка при смене учёта не учитывает собранный, но не уехавший товар.
- Заголовки «Сегодня/Вчера» в журнале считаются по часам компьютера.
