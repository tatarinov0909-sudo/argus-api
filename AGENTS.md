# Argus API

Перед проектированием функции прочитать общий принцип масштабируемости:
`../argus-product/rules/scalability.md`. Если решение требует индивидуального
кода или ручного сопровождения каждого продавца, его нельзя внедрять.
Правило и продуктовые требования хранятся в основном репозитории, не создавать
здесь расходящуюся копию.

Секреты не выводить и не включать в коммиты. Сохранять серверную изоляцию
складов и продавцов. Записывающие интеграционные тесты запускать только на
явно подтверждённой отдельной тестовой базе, никогда через рабочий `.env`.
